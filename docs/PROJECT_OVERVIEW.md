# ReadFlow – Project Overview

ReadFlow is a Progressive Web App (PWA) for personal PDF reading and English-to-Vietnamese
vocabulary learning. It is designed to run entirely on free-tier cloud infrastructure.

## Goals

- Read PDFs comfortably on any device.
- Select English words/phrases and get Vietnamese translations via AI.
- Build a personal vocabulary list from reading.
- Annotate PDFs with highlights, bookmarks, and notes.
- Read offline after downloading a book.
- Synchronise data across multiple devices via the cloud.

## Non-Goals (MVP)

- OCR of scanned PDFs.
- Real-time collaboration.
- WebSocket notifications.
- Mobile native app.
- Social sharing.
